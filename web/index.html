Sync a directory between two machines with the rsync you already have, over an encrypted SP2P connection. No SSH or open ports needed.

  1. On the source machine, start the sync. This prints a transfer code.
  2. On the destination machine, create ./backup, then run this with CODE replaced by that code.

Everything after -- goes to rsync unchanged. Each run needs a fresh code from the sender.
